使用步骤

  1. 账号卡片上的“设为当前”会让新的请求只使用该账号；切换即时生效，不用重启服务。
  2. “禁用”用于保留账号但暂时不参与轮询；旧账号额度用完时建议禁用。
  3. “查额度”读取 Quick 官方月度/会话分钟数；额度为 0 时上游会暂停回复。
  4. “刷新”会更新 OAuth token；过期后代理也会自动刷新。
  5. Claude Code 仍通过 CC Switch（127.0.0.1:15721）访问本服务，Web 管理台只管理上游账号。
  6. 不要在 Quick Web 打开/继续代理会话：Quick Web 是云端实例，不能读写本机文件；需要查看时用 Quick 桌面端，或直接在 Claude Code 里继续。
